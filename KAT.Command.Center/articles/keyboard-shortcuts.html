Advanced · keyboard reference

Keyboard Shortcuts

Use keyboard shortcuts to refresh high-traffic sections, move through Work Items, and submit comment dialogs without leaving the keyboard.

Application refresh shortcuts

The refreshes you reach for most often have keys.

F5
Refreshes the whole site: every section, and the rail's badges with them. On Tools > Grazer, re-runs the last submitted search; before the first accepted search, it does nothing. On Tools > Repository Status, rescans the roots and checks every repository's local status, without fetching; use Ctrl+F5, or Ctrl+Click, there for a manual fetch. See Refreshing.
Ctrl+Shift+W
Re-runs every saved Work Items query, the same as the ↻ in the Work Items header: the rail's query counts and the results of the query that is open.
Ctrl+Shift+Q
Re-runs just the open query. With no query open, it does nothing.
Ctrl+Shift+R
Refreshes the Release Pipeline, the Release Pipeline KPI tile, and Release Differences together, because all three come from one fetch.
Ctrl+Shift+C
Refreshes the CalcEngine Pipeline. On a site with no CalcEngine patterns there is no section to refresh, so the key does nothing.

Access keys

The site picker in the app bar, and the From/To pickers and CalcEngine Patterns box in the section headers, have access keys. Press and release Alt on its own to underline their letters; press it again, or click anywhere, to hide them. Like the refresh shortcuts, they are ignored while a dialog is open - a dialog uses Alt for its own fields.

Alt+S
Opens the site picker with its search box focused. Type to narrow the list, ↑/↓ (or Page Up/Page Down) to move, Enter to load the highlighted site and Esc to close it without changing anything. With the closed picker focused, typing a letter opens it with that letter already searched.
Alt+F / Alt+T
Focus the From or To release picker, switching to the Release Pipeline page first. Picking a release refreshes the Release Pipeline straight away; there is nothing further to press.
Alt+C
Focus CalcEngine Patterns, switching to the CalcEngine Pipeline page first. Press Enter in the box to refresh the CalcEngine Pipeline with the new patterns. Nothing else is re-fetched.

Work Items grid

With a query open, the grid can be driven from the keyboard without reaching for the mouse. The keys match GitHub's, so they should already be in your fingers. They also work when focus is on a button - after clicking a rail entry or a header button, for instance - so you do not have to click back into the grid first. The exception is when you are typing in a box, such as the site search or a filter box, where a letter means what it always means.

Navigation
j
Move down one row, wrapping from the last row back to the first. With nothing selected yet, selects the first row.
k
Move up one row, wrapping from the first row round to the last. With nothing selected yet, selects the last row.
o / Enter
Open the selected row's work item detail - the same thing clicking its title does. Does nothing when no row is selected.
Esc
Leaves Return Triage Tasks select mode if it is active; otherwise unselects the currently selected row. With both, the first press leaves select mode and the second unselects the row.
Actions - Grid focused

c
Add Comment to the selected row. Defaults: Comment = Default Comment Text.
r
Return Task to previous owner. Defaults: Triage = Pending, Reassign To = previous owner, Comment = Default Return Task Comment.
t
Triage Task. Defaults: Triage = Triaged, Comment = Default Triage Comment.
x
Close Task. Defaults: State = Closed, Comment = Default Close Task Comment.

Space

Comment and new work item modals

Ctrl+Enter
Validates and submits current edits. To enable this feature, you must turn on Submit comment dialogs with Ctrl+Enter in Settings.
Esc
Closes the dialog. In the single-item comment and new work item dialogs, the first press inside Comment, Description, or Repro Steps asks whether to discard only if the dialog has changes from its initial values. Press Esc again to discard and close, or choose Keep editing. Cancel and Esc outside those text boxes close without confirmation.
Keyboard Mnemonics
In single-item comment dialogs, access keys focus the editable fields via Alt+ appropriate key. For example, Alt+C would focus Comment. Press and hold Alt to underline the hotkey for each field.

Repository Status

Besides F5 (see above), the Tools > Repository Status table, its menus and its dialogs work from the keyboard. Each row's … actions button is always there, so Tab reaches it.

Enter / Space / → / ←
On a focused repository row, Enter or Space expands or collapses it to show its branches and worktrees; → expands and ← collapses. Expansion and focus survive background checks.
↓ / Enter on … or ▾
Opens a row's actions menu, or the Batch Action menu, with its first available item focused. ↑/↓ and Home/End move, → opens a remote's Fetch / Push / Force Push entries and ← closes them, Enter chooses, and Esc closes the menu and returns focus to its button. Pressing the button again also closes it.
Space on a row checkbox
In batch mode, ticks or clears that row; All in the header does every applicable row on screen. Continue runs the batch action, Cancel leaves batch mode, and so does Esc while you are still choosing rows; once the action is running, Cancel stops it instead.
Esc in a dialog
Cancels the Pull preview, the Commit / Push review, the worktree cleanup review or a confirmation, changes nothing (a "Don't ask me" switch is saved only when you confirm), and returns focus to the control that opened it.
Ctrl+Enter in the commit message
Confirms the Commit / Push review, like its button. Enter alone starts a new line.

Settings

Ctrl+Enter
Save every page, from any box. Always on - it does not depend on the comment dialogs setting. While a query is open for Add or Edit, it saves just that query back to the list instead.
Enter
In an account's boxes on Profile, signs in to that one account and leaves Settings open whatever the answer. Anywhere else it does nothing, so it never saves the form.
Esc
Close without saving, restoring the saved themes, color mode and density if you were previewing Display changes. While a query is open for Add or Edit, it drops just that query's changes and returns to the Work Items page. While you are dragging a list item, it puts the item back instead.
Alt+↑ / Alt+↓
On a focused grip in a reorderable list (the Work Items queries and the Repository Status roots), moves that item up or down one place; the new position is announced. The order is saved with Save.
