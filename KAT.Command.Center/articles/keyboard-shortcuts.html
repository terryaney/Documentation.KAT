Advanced · keyboard reference

Keyboard Shortcuts

Use keyboard shortcuts to refresh high-traffic sections, move through the Work Items, CalcEngines, Site Scope and Repository Status tables, and submit comment dialogs without leaving the keyboard.

Application refresh shortcuts

The refreshes you reach for most often have keys.

F5
Refreshes the whole site: every section, and the rail's badges with them. On Tools > Grazer, searches with the current root, patterns and result mode plus existing chips; pending search text is not added, and no search runs when there are no chips. On Tools > Repository Status, checks local status for the repositories the table lists, without fetching or rescanning the roots; use Ctrl+F5, or Ctrl+Click, there to fetch them. See Refreshing.
Ctrl+Shift+W
Re-runs every saved Work Items query, the same as the ↻ in the Work Items header: the rail's query counts and the results of the query that is open.
Ctrl+Shift+Q
Re-runs just the open query. With no query open, it does nothing.
Ctrl+Shift+R
Refreshes the Pipeline page and the Releases · Pipeline tile together, because both come from one fetch. While an invalid From/To pair is held on the Pipeline page, it does nothing until you fix or restore the pair.
Ctrl+Shift+C
Refreshes only CalcEngines, including its dashboard tile. With no CalcEngine patterns, or while a dialog is open, the key does nothing.

Access keys

The From/To pickers on the Pipeline page and the CalcEngine Patterns box on CalcEngines have page-local access keys. On the Pipeline page, hold Alt to underline the From and To letters; they disappear when you let go. CalcEngine Patterns has no visible Alt cue. Like the refresh shortcuts, these keys and / are ignored while a dialog is open - a dialog uses Alt for its own fields.

/
Opens the site picker with its search box focused, unless you are typing in a box. Type to narrow the list, ↑/↓ (or Page Up/Page Down) to move, Enter to load the highlighted site and Esc to close it without changing anything. With the closed picker focused, typing a letter opens it with that letter already searched.
Alt+F / Alt+T
Open the From or To release picker. These work only while the Pipeline page is showing. Picking a valid pair refreshes the Pipeline straight away; there is nothing further to press.
Alt+C
Focus CalcEngine Patterns only while the CalcEngines page is visible and the box is enabled. It does not switch pages. Press Enter to apply the temporary patterns and refresh only CalcEngines; selecting a site again or restarting restores the defaults.

Work Items grid

With a query open, the grid can be driven from the keyboard without reaching for the mouse. The keys match GitHub's, so they should already be in your fingers. They also work when focus is on a button - after clicking a rail entry or a header button, for instance - so you do not have to click back into the grid first. The exception is when you are typing in a box, such as the site search or a filter box, where a letter means what it always means.

Navigation
j
Move down one row, wrapping from the last row back to the first. With nothing selected yet, selects the first row.
k
Move up one row, wrapping from the first row round to the last. With nothing selected yet, selects the last row.
o / Enter
Open the selected row's work item detail - the same thing clicking its title does. Does nothing when no row is selected.
Space
Open the selected row's ⋯ menu. In Return Triage Tasks select mode it ticks the row instead (see below).
Esc
Leaves Return Triage Tasks select mode if it is active; otherwise unselects the currently selected row. With both, the first press leaves select mode and the second unselects the row.
Actions - Grid focused

Each acts on the selected row, and each is also on the row's ⋯ menu. The task actions open the row's detail in its edit form.
e
Edit Task. Defaults: Comment = Edit Task default.
t
Triage. Defaults: Triage = Triaged, Comment = Triage default.
r
Return Task to the previous owner. Defaults: Triage = Pending, Assigned To = previous owner, Comment = Return Task default.
c
Close Task. Defaults: State = Closed, Comment = Close Task default.
v
View in TFS in your default browser.
l
Copy Link to the work item in TFS.
i
Copy ID, as #123456, for git commits and messages.
Return Triaged Tasks
Space
Tick or untick the selected row's checkbox while a batch workflow is active.

Work item edit form and dialogs

Ctrl+Enter
Validates and saves current edits in the work item edit form, the batch Return Task dialog and the new work item dialog. To enable this feature, you must turn on Use Ctrl+Enter to submit work item changes in Settings.
Esc
Leaves the edit form or closes the dialog. In a changed Comment, Description, or Repro Steps, the first press asks whether to discard. Press Esc again to discard, or choose Keep editing. Cancel and Esc outside those text boxes leave without confirmation. With a tags or assignee list open, Esc closes the list first.
Ctrl+V
With an image on the clipboard, adds it to the comment or description. See pasted images.
Keyboard Mnemonics
In the new work item dialog, access keys focus the editable fields via Alt+ appropriate key. Press and hold Alt to underline the hotkey for each field.

CalcEngines and Site Scope

The CalcEngines and Site Scope tables use the Work Items grid's row keys. As there, they work when focus is on a button but not while you are typing in a box.

j / k
Move down or up one row, wrapping at either end. With nothing selected yet, j selects the first row and k the last.
Space
On CalcEngines, opens the selected row's ⋯ menu. On Site Scope, opens the selected row's details.
Esc
Closes an open menu or the details first; otherwise unselects the row.

Repository Status

Besides F5 (see above), the Tools > Repository Status table, its menus and its dialogs work from the keyboard. Checkout rows have a … actions button; branch rows do not have a menu.

j / k
Move down or up one row, wrapping at either end, through every row on screen, including an expanded repository's branch and worktree rows. A repository opened from What's Happening is already selected, so j/k continue from it.
Space
Opens the selected row's … menu. Branch rows have no menu, so it does nothing there. In batch mode it ticks the selected row instead.
→ / ←
On a focused repository row, → expands it to show its branches and worktrees and ← collapses it. Expansion and focus survive background checks.
Esc
Closes an open menu first; otherwise unselects the row. Changing Show also unselects it.
Enter / Space on … or ▾
Opens a row's actions menu or the Batch Action menu. A row menu first focuses its container. In a menu, ↑/↓ and Home/End move, → opens a remote's Fetch / Push / Force Push entries and ← closes them, Enter chooses, and Esc closes the menu and returns focus to its button. Pressing the button again also closes it.
Space on a row checkbox
In batch mode, ticks or clears that row; All in the header does every applicable row on screen. Continue runs the batch action, Cancel leaves batch mode, and so does Esc while you are still choosing rows; once the action is running, Cancel stops it instead.
Esc in a dialog
Cancels a Pull, Push, Commit or worktree delete review or another confirmation, changes nothing (a "Don't ask me" switch is saved only when you confirm), and returns focus to the control that opened it.
Ctrl+Enter in the commit message
Confirms the Commit review, like its button. Enter alone starts a new line.

Settings

Ctrl+Enter
Save every page, from any box. Always on - it does not depend on the comment dialogs setting. While a query is open for Add or Edit, it saves just that query back to the list instead.
Enter
In an account's boxes on Profile, signs in to that one account and leaves Settings open whatever the answer. Anywhere else it does nothing, so it never saves the form.
Esc
Close without saving, restoring the saved themes, color mode and density if you were previewing Display changes. While a query is open for Add or Edit, it drops just that query's changes and returns to the Work Items page. While you are dragging a list item, it puts the item back instead.
Alt+↑ / Alt+↓
On a focused grip in a reorderable list (the Work Items queries and the Repository Status roots), moves that item up or down one place; the new position is announced. The order is saved with Save.
