Keyboard Shortcuts

Use keyboard shortcuts to refresh high-traffic sections, move through Work Items, and submit comment dialogs without leaving the keyboard.

Application refresh shortcuts

The refreshes you reach for most often have keys. F5 is the app bar's whole-site Refresh. The others each do exactly what that section's ↻ button does: re-fetch that section and leave every other card alone.

F5
Refreshes the whole site, the same as the app bar's Refresh.
Ctrl+Shift+W
Re-runs every saved Work Items query: the chips and the results of whichever queries are open.
Ctrl+Shift+Q
Re-runs just the open query, the same as the ↻ at the end of its results' action bar. With no query's results open, it does nothing.
Ctrl+Shift+R
Refreshes the Release Pipeline, the Release Pipeline KPI tile, and Release Differences together, because all three come from one fetch.
Ctrl+Shift+C
Refreshes the CalcEngine Pipeline. On a site with no CalcEngine filter there is no card to refresh, so the key does nothing.

Application bar

The bar across the top of the window has access keys for its site picker, its Refresh and its filter boxes. Press and release Alt on its own to underline their letters; press it again, or click anywhere, to hide them. Like the refresh shortcuts, they are ignored while a dialog is open - a dialog uses Alt for its own fields.

Alt+S
Opens the site picker with its search box focused. Type to narrow the list, ↑/↓ (or Page Up/Page Down) to move, Enter to load the highlighted site and Esc to close it without changing anything. With the closed picker focused, typing a letter opens it with that letter already searched.
Alt+R
Refresh, the same as F5.
Alt+F / Alt+T / Alt+C
Focus From Release #, To Release # or CalcEngine Filter, showing the filter row first if it was hidden.
Enter
In a release box, refreshes the Release Pipeline with the new numbers; in CalcEngine Filter, refreshes the CalcEngine Pipeline. Nothing else is re-fetched.

Work Items grid

With a query open, the grid can be driven from the keyboard without reaching for the mouse. The keys match GitHub's, so they should already be in your fingers. They also work when focus is on one of the app bar's buttons - after clicking Refresh, for instance - so you do not have to click back into the grid first. The exception is when you are typing in a box, such as the site search or a filter box, where a letter means what it always means.

Navigation
j
Move down one row, wrapping from the last row back to the first. With nothing selected yet, selects the first row.
k
Move up one row, wrapping from the first row round to the last. With nothing selected yet, selects the last row.
o
Open the selected row's work item detail - the same thing clicking its title does. Does nothing when no row is selected.
Esc
Unselects the currently selected row.
Actions - Grid focused

All actions open 'edit' dialog for a task's Assigned To, Comment, State and Triage. These same actions are also available on each row's Context Menu.
c
Add Comment to the selected row. Defaults: Comment = Default Comment Text.
r
Return Task to previous owner. Defaults: Triage = Pending, Reassign To = previous owner, Comment = Default Return Task Comment.
t
Triage Task. Defaults: Triage = Triaged, Comment = Default Triage Comment.
x
Close Task. Defaults: State = Closed, Comment = Default Close Task Comment.
Return Triaged Tasks
Space
Tick or untick the selected row's checkbox while a batch workflow is active.

Comment modals

Ctrl+Enter
Validates and submits current edits. To enable this feature, you must turn on Submit comment dialogs with Ctrl+Enter in Settings.
Esc
Closes the dialog. If you have typed anything, the first press asks whether to discard your edits instead of closing. Press Esc again to discard and close, or keep typing to carry on. Cancel closes straight away - it is already an explicit "throw this away".
Keyboard Mnemonics
Access keys focus the editable fields via Alt+ appropriate key. For example, Alt+C would focus Comment. Press and hold Alt to underline the hotkey for each field.

Settings

Ctrl+Enter
Save every page, from any box. Always on - it does not depend on the comment dialogs setting. While a query is open for Add or Edit, it saves just that query back to the list instead.
Enter
In an account's boxes on Profile, signs in to that one account and leaves Settings open whatever the answer. Anywhere else it does nothing, so it never saves the form.
Esc
Close without saving, restoring the saved themes, color mode and density if you were previewing Display changes. While a query is open for Add or Edit, it drops just that query's changes and returns to the Work Items page.
