CalcEngine Pipeline

Read environment versions, approve or promote files, resolve checkouts, inspect version history, and download the exact environment variant you need.

Sample Pipeline

ConsequenceApprovals and Promotions move CalcEngines to associated site environments. Ensure the CalcEngine has been tested before actions taken.

Notable Features

  1. Supports 2 environment (QA/PROD) or 4 environment (DEV/QA/UAT/PROD) CalcEngines showing exactly where the 'latest' CalcEngine is running
  2. Hover over environment chips to see their state, who uploaded, approved, or promoted and when each environment state occurred. UAT reports a promotion only when the version arrived by promotion - uploading a test version directly replaces that history, so the chip says uploaded instead.
  3. Use the section tools to narrow fetched rows by name, checkout user, environment, blocked promotions, or production moves.
  4. Displays checkout owners. Upper (_PROD) checkouts can block the TFS Release Pipeline; clicking a checkout chip checks the file in, forcibly when it belongs to someone else.
  5. Check Mine In checks in every CalcEngine you currently hold, in one confirmed action.
  6. The rail badge and What's Happening rows follow the shared dashboard rules for checkouts and recent moves by someone outside the KAT team; see Rail badges and What's Happening.
  7. Approve and Promote CalcEngines to the 'next environment' when ready by clicking version chip. Both ask for an authority email - the person signing the move off - prefilled with your KAT Management Site email. It cannot be left blank, and it cannot be the person whose file is moving: the Approval Authority may not be whoever uploaded the test CalcEngine, and the Promotion Authority may not be whoever uploaded the live CalcEngine.
  8. Each row's ⋯ button opens its actions: View History (on rows with a version still to move), Manage to open the CalcEngine on the Conduent Management Site, and a Download item for each environment variant.
Conduent Management Site

The management site opens in your default browser, not inside Command Center. You can reach it from two places, and where you start decides where you land.

Manage, in a CalcEngine's ⋯ menu - opens CalcEngine Management with that file already selected: .../default.aspx?startPage=lnkCalcEngineManagement&startCE=Conduent_Nexgen_SAMPLE_BRD_SE. The startCE value is the CalcEngine name without its file extension, and always the base file - never the _PROD_ variant.
On the KPI tile - opens the management site's home page, with no CalcEngine selected. This button is present even when the KPI has nothing to show, which is the point: it is how you get to the site when you are not signed in to KAT DataStore yet.
Download Preferences

When downloading CalcEngines, by default files are downloaded to your Downloads folder. You can set the Always Replace and Auto Open settings as you desire.

Always Replace - Automatically replaces files without prompting for new file name. Default is false.
Auto Open - Automatically opens the CalcEngine after download in Excel. Default is false.

CalcEngine Pattern Expressions

By default, each site already has CalcEngine Patterns that include the CalcEngines known at the time of the latest release. Change those listing patterns in the CalcEngine section head. Alt+C opens the CalcEngine page and focuses the field; Enter refreshes only CalcEngine. The separate search box in the same tools row only narrows rows that are already fetched.

Expression Rules

  1. Filter expressions are comma-separated and use OR logic when multiple expressions are provided.
  2. A plain value simply matches an exact CalcEngine name. See first example below.
  3. Instead of a plain value, the following commands are available: StartsWith:pattern, EndsWith:pattern, or Contains:pattern. See second example below.
  4. Chain commands within a single expression with ! for AND NOT logic. See third example below.
  5. To make a chained command be simply AND logic, prefix a later command with ^. See fourth example below.
Filter Result
Conduent_Nexgen_SAMPLE_BRD_SE.xlsm Matches exact name of a CalcEngine.
StartsWith:Conduent_Nexgen_ Names beginning with that prefix.
StartsWith:Conduent_Nexgen_!EndsWith:BRD_SE Starts with the prefix but does not end with BRD_SE.
StartsWith:Conduent_Nexgen_!^Contains:_BRD_SE. Starts with the prefix and contains _BRD_SE.

Version history

See the historical differences between the lowest and highest versions of a CalcEngine. Each 'checkout line' identifies its filename and current owner. The base CalcEngine (DEV/QA) and its production-suffixed counterpart (UAT/PROD) have separate checkouts, so the same owner can appear twice.

Recognizing probable hotfixes

A direct upload to the upper CalcEngine can introduce versions that do not exist in lower history. A warning triangle marks these as probable patches.

In the example below, DEV is 1.1696, QA is 1.1688, and PROD is 1.16355. The lookup finds the shared baseline 1.1635 and brings back all five probable patches, 1.16351 through 1.16355. The PROD checkout line is marked (blocking) because an upper checkout blocks the TFS Release Pipeline.
