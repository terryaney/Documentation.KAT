CalcEngines

Read environment versions, approve or promote files, resolve checkouts, inspect version history, and download the exact environment variant you need.

Open Releases > CalcEngines for the selected site. It uses your KAT DataStore sign-in from Settings > Profile; a TFS personal access token is not required.

Read environment status

ConsequenceApprovals and promotions move CalcEngines to the associated site environments. Ensure the CalcEngine has been tested before taking either action.

Notable Features

  1. Supports two-environment (QA/PROD) and four-environment (DEV/QA/UAT/PROD) sites. A green arrow marks a version ready to move forward; a red, struck-through QA version means the upper file has a newer version. Two-environment sites approve within one file and do not have a separate promotion step.
  2. Hover over environment chips to see who uploaded, approved, or promoted, the authority when recorded, and when it happened. A blocked chip's tooltip starts with Blocked: {reason}, naming the QA and newer upper versions, then a blank line before the standard metadata. UAT reports a promotion only when the version arrived by promotion - uploading a test version directly replaces that history, so the chip says uploaded instead.
  3. Use the section tools to narrow fetched rows by name, checkout user, environment, blocked promotions, or production moves. In Show, each option's count is its matching rows. My Checkouts and Team Member Checkouts have amber dots when your or other people's upper-file checkouts, respectively, block the TFS Release Pipeline. Blocked Promotions has an amber dot for anyone's blocking upper-file checkouts, upgraded to red if any QA version is blocked by a newer upper version. Flagged labels are bold in the dot's color, including the selected label; count chips stay neutral. No other Show options have warning or error dots. The closed Show picker also has a dot at its edge: red when any option has a red dot, otherwise amber when any has an amber dot, whatever is selected.
  4. Displays checkout owners. Upper (_PROD) checkouts can block the TFS Release Pipeline. Clicking your checkout chip asks to check it in; someone else's asks for Force Check In.
  5. Check Mine In ({n}) checks in only your checkouts in the rows left visible by Filter and Show, after confirmation. The count changes with those filters and the button hides at zero. The app's footer notice bar identifies each file that could not be checked in.
  6. The rail badge and What's Happening rows follow the shared dashboard rules for checkouts and recent moves by someone outside the KAT team; see Rail badges and What's Happening.
  7. Approve and Promote CalcEngines to the 'next environment' when ready by clicking version chip. Both ask for an authority email - the person signing the move off - prefilled with your KAT Management Site email. It cannot be left blank, and it cannot be the person whose file is moving: the Approval Authority may not be whoever uploaded the test CalcEngine, and the Promotion Authority may not be whoever uploaded the live CalcEngine.
  8. Each row's ⋯ button opens its actions: View History (on rows with a version still to move), Manage to open the CalcEngine on the Conduent Management Site, and Download items for available versions. When environments share a version, only the upper environment's download is offered.

Filter matches both the base and upper filenames and checkout email addresses. Show combines selected environments with OR; choosing a status such as My Checkouts replaces the environment selection. Blocked Promotions includes both newer upper versions and upper checkouts. A header environment chip clears Filter and selects that environment; zero-count header chips and Show options are hidden. The title keeps the total while the footer shows the filtered count.

Click Name or an environment heading to sort. In card view, use the Sort picker instead. Filter, Show and sort survive refreshes of the same selected site, but reset when you select a site again or restart.

Checkouts do not prevent manual approval. For a promotion, if someone other than you or the entered authority holds the upper file, the confirmation warns that it will be force-checked in first. If that check-in fails, the promotion stops.

Use ↻ or Ctrl+Shift+C to refresh only CalcEngines. F5, selecting a site, or changing the DataStore sign-in also reloads it. There is no CalcEngine polling timer; the dashboard ages its cached checkout and recent-move notices every ten minutes. Refresh shortcuts do nothing while a dialog is open, and CalcEngines refresh does nothing when no patterns are set.

Conduent Management Site

The management site opens in your default browser, not inside Command Center. You can reach it from two places, and where you start decides where you land.

Manage, in a CalcEngine's ⋯ menu - opens CalcEngine Management with that file already selected: .../default.aspx?startPage=lnkCalcEngineManagement&startCE=Conduent_Nexgen_SAMPLE_BRD_SE. The startCE value is the CalcEngine name without its file extension, and always the base file - never the _PROD_ variant.
On the KPI tile - opens CalcEngine Management with no CalcEngine selected. This button is present even when the KPI has nothing to show, which is the point: it is how you get to the site when you are not signed in to KAT DataStore yet.

Both try to sign you in to the site with your KAT DataStore credentials first. A row's Manage action shows busy dots beside its name; the tile button shows Processing until the browser opens. Without credentials, or when that sign-in fails, the site opens anyway and asks you to sign in.

Download a CalcEngine

Choose an environment's Download item from the row's ⋯ menu. Busy dots appear beside the name and that row's other downloads are disabled until it finishes. Files go to your Windows Downloads folder using the original filename; DEV and UAT downloads no longer add _Test to it.

If the file already exists, choose Replace, Browse for another location, or Cancel. A locked file offers Browse or Cancel; choosing another location reuses the downloaded file instead of fetching it again. A failed download leaves an existing file untouched.

Download Preferences

All three switches are in Settings > Releases > CalcEngine Download, not Profile.

Always replace existing files - Replaces a same-name file without asking. Off by default; a locked file still needs another location.
Automatically open downloaded CalcEngines - Opens the saved file in its associated application. Off by default.
Show confirmation after downloading CalcEngines - Shows the saved path with Copy Path, Open Folder, and Open CalcEngine. On by default; disabled while automatic opening is on, without losing its value.

The saved-file dialog can also turn on automatic opening for future downloads. Copy Path copies through Windows, including Clipboard History when enabled. Successful automatic opening is silent; if opening fails, the saved-file dialog shows the error and keeps the file's path available.

CalcEngine Pattern Expressions

Sites with configured CalcEngines start with catalog patterns. Change them in the CalcEngine Patterns box and press Enter to refresh only CalcEngines. While this page is visible, Alt+C focuses the enabled box; it does not switch pages and has no visible Alt cue. It does nothing while a dialog is open. The separate Filter box only narrows rows already fetched.

Pattern changes are temporary: selecting a site again, even the same one, or restarting restores the catalog defaults. They are not saved in Settings. Clearing Patterns disables the listing; non-API sites without defaults can enter custom patterns, while API sites cannot edit them.

Expression Rules

  1. Filter expressions are comma-separated and use OR logic when multiple expressions are provided.
  2. A plain value simply matches an exact CalcEngine name. See first example below.
  3. Instead of a plain value, the following commands are available: StartsWith:pattern, EndsWith:pattern, or Contains:pattern. See second example below.
  4. Chain commands within a single expression with ! for AND NOT logic. See third example below.
  5. To make a chained command be simply AND logic, prefix a later command with ^. See fourth example below.
Filter Result
Conduent_Nexgen_SAMPLE_BRD_SE.xlsm Matches exact name of a CalcEngine.
StartsWith:Conduent_Nexgen_ Names beginning with that prefix.
StartsWith:Conduent_Nexgen_!EndsWith:BRD_SE Starts with the prefix but does not end with BRD_SE.
StartsWith:Conduent_Nexgen_!^Contains:_BRD_SE. Starts with the prefix and contains _BRD_SE.

Version history

Choose View History on a row with a version still to move. The dialog opens while history loads, then lists versions from newest to oldest with dates, authors and comments. Each checkout line identifies its filename and current owner. The base CalcEngine (DEV/QA) and its production-suffixed counterpart (UAT/PROD) have separate checkouts, so the same owner can appear twice.

Work item references in comments open Work Item Detail inside Command Center. Closing it returns to History at the same scroll position, unless you changed sites. A late history response cannot replace a newer dialog or another site's history.

Recognizing probable hotfixes

A direct upload to the upper CalcEngine can introduce versions that do not exist in lower history. A warning triangle marks these as probable patches; its legend stays in the dialog footer while you scroll.
