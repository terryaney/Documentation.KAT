Notable Features

  1. See what is being released in latest PROD deployment. See commits across all repositories required to build the site or API to be included in the current release (not just commits isolated to the site or API)
  2. Obeys the same From and To release resolution rules as the Release Pipeline. See From and To Detection if you need to enter a specific range for historical audits.
  3. Show Pending option to see additional release candidates newer than current From release and even commits that haven't been published yet. Try it out in the interactive sample above.
  4. View any commit on TFS via the commit hash link.
  5. View associated TFS work items via the #work-item reference in commit comments.
  6. View complete commit comment via details button link when comment has been truncated.
