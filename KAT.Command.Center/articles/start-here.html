Start with the signal, then choose the action.

KAT Command Center brings together information about Tasks, Builds, Releases, CalcEngines, Site Metrics, and more, helping KAT team members stay on top of everything required to keep our sites and APIs running and healthy.

Step 01

Select a site

Choose the site whose release and CalcEngine state you need to inspect.

Note: Work Items and Site Scope are independent of the selected site.

Step 02

Read the status

Use KPI tiles for headlines, then expand a detail card for evidence and controls.

Step 03

Act deliberately

Review the confirmation and consequence before approving, redeploying, or cleaning up.

Common Tasks

Work Pressure
Stay on top of your tasks with Work Item queries you configure. You monitor task severity, priority, age, tags, and item details. Set up a query that answers the questions you care about most.
Release Management
Using the Release Pipeline and Release Differences, inspect environment deployments, verify code changes within each release, trigger deployment actions, and perform stale release cleanup tasks.
CalcEngines
at a Glance
The CalcEngine Pipeline provides an overview of a site's CalcEngine manifest; monitor CalcEngine environment deployments, review differences between versions, approve/promote changes as needed, or download CalcEngines for in-depth inspection.
Finding Your Way
Every ? button on the dashboard opens that section's specific help to guide you. Use the search box to find a topic, the browser's Back button to return to where you were, and switch back to the app window when you are done.
Having Problems?
Work with the KAT team and the Diagnostics card when problems arise and a simple retry does not resolve the issue.
