Setting Up KAT Access

KAT Command Center requires three forms of authorization. The first is your KAT Management site user credentials, the second is your Conduent network account, and the third is a TFS Personal Access Token (PAT). The PAT will be written and stored in a local file; the two passwords are never written unless you ask for them to be - see Remember me below.

Setting Up the PAT

The PAT enables the Release and Work Items management application features. Follow the steps below to set up your PAT for KAT Command Center.

  1. Visit TFS Personal Access Tokens (PAT).
  2. In the Personal access tokens page, click the 'Add' button to create a new token.
  3. Use KAT PAT as the name, select 1 year for expiration, and leave the default All scopes selected for authorized scopes.
  4. Click 'Create Token' to generate your token.
  5. Copy the generated token value. Click the 'Profile' icon in KAT Command Center and paste the value in the PAT field. Click 'OK' to save.
File Hand EditsYou can also edit Tfs.Secrets.json by hand. The app reads it once at startup, so a hand edit takes effect after you restart or immediately if you reopen the Profile dialog, which reads the file fresh each time it opens.

Providing KAT Management Credentials

The KAT Management Site credentials enable CalcEngine Pipeline and Site Metrics functionality. To ensure proper operation, follow the steps below.

  1. Click the 'Profile' icon in KAT Command Center.
  2. Enter your KAT Management site user credentials in the appropriate fields.
  3. Click 'OK' to save and complete the sign-in process.

Remember me

By default the KAT Management and Conduent passwords live in memory only, so the dialog asks for them every launch. Tick Remember me at the bottom of the dialog and both are saved instead, and the app signs in with them silently on the next launch - you only see the dialog if one of them is rejected.

They are encrypted with Windows for your account, on this machine. Copied elsewhere, or read by another Windows user, the saved values are useless. What that does not protect against is anything already running as you, which is why it is off unless you turn it on.

Untick the box and both saved passwords are deleted immediately. A password that stops working is also dropped on its own, so a change on your side heals itself - you are asked once, and remembered again from there.

Common Tasks

Work Pressure
Stay on top of work-item pressure with Work Item queries you configure. You monitor task severity, priority, age, tags, and item details. Set up a query that answers the questions you care about most or that help answer what you have been working on.
Release Management
Using the Release Pipeline and Release Differences, inspect environment deployments, verify code changes within each release, trigger deployment actions, and perform maintenance cleanup tasks.
CalcEngines at a Glance
The CalcEngine Pipeline provides an overview of a site's CalcEngine manifest; monitor CalcEngine environment deployments, review differences between versions, approve/promote changes as needed, or download CalcEngines for in-depth inspection.
Having Problems?
Work with the KAT team and the Diagnostics card when problems arise and a simple retry does not resolve the issue.
Finding Your Way
Every ? button on the dashboard opens this site at the section that explains it. Use the search box to find a topic, the browser's Back button to return to where you were, and switch back to the app window when you are done.

Settings

The pencil in the app header opens Settings. It deliberately shows only the settings a person chooses — everything else in the settings file is state the app writes for itself, and editing those by hand only invites the app to overwrite you. The link at the bottom of the dialog opens the raw file in a text editor — VS Code when it is installed, Notepad otherwise — for anything not covered here.

Notable Features

  1. All four comment defaults start blank — this app does not guess the sentence you want on a work item. Set them once and every matching modal opens with it. See Comment or reassign for which default reaches which modal.
  2. Both poll values may be left blank to use the app's built-in defaults.
  3. Queries can only be removed here, not added or edited — adding one goes through Add Query, which validates it. Removals are struck through and applied only when you press OK, so Cancel genuinely cancels them.
  4. Saved settings reach the open dashboard immediately; no refresh is needed.
  5. When a newer build is waiting, an Update button appears in the toolbar beside the theme toggle - white, with a green dot after the word that pulses a few times as it appears. Pressing it replaces the app and restarts it, so finish what you are doing first.
