Search local folders with Grazer

Find the same setting, phrase or old name across your local folders without opening each project. Grazer, under Tools, searches multiple literal terms together, with a case / whole word setting for each. Review matching lines grouped by folder and file, or switch to file or folder names for a broader view. Searches run only when you ask, never while you type or on a timer.

For replacements, each changed line shows its Old and New text before you write. Apply changes to a line, file or folder, or use Replace All; dismiss matches you want to leave alone. Grazer re-reads files before writing and refuses files changed since the search, preserving their encoding and line endings. ZIP entries, when ZIP searching is enabled, remain read-only. No backup files are created, so keep changes under source control. See Grazer in Help.

Your repositories, at a glance

Repository Status, under Tools, brings your local Git repositories into one view. See checked-out branches, incoming and outgoing commits, staged and unstaged changes, and conflicts without visiting each folder. Expand a repository to inspect its other branches and linked worktrees, each with its own status. Filter by root or path, focus on Needs Attention, or use a reason chip to find a specific problem.

Monitoring continues while you work elsewhere in the app or minimize it. By default, local status is checked every two minutes and upstream remotes are fetched every 30 minutes; fetching updates incoming counts but never pulls or edits your files. Incoming commits and conflicts also appear in What's Happening. Use F5 to rediscover repositories and check local status, or Ctrl+F5 to fetch now.

Act on one checkout or select several for a batch Pull, Push, Commit or worktree cleanup. Sync pulls then pushes a diverged checkout, using your Git pull configuration. Commit reviews every change, including untracked files; force pushes always use a reviewed lease and refuse a remote branch that changed afterward. Worktree cleanup reviews the selected worktrees, warns when removal requires force, and keeps their branches. Show Differences and terminal shortcuts let you continue in your preferred tools. See Repository Status in Help.
