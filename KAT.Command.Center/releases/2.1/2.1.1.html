• Repository Status adds focused views for worktrees, local branches and checkouts off main or master, and lets you search repository names, paths and branches. Remote branches can be shown from Settings.
  • Duplicate repository names gain just enough parent-path context to distinguish them. The list sorts by these labels, which stay stable while you type.
  • Repository Status opens a changed-files dialog with added and removed line counts, and lets you open each supported file in your configured Git diff tool without first opening a terminal. Removed-line counts now use the correct red color. Learn more.
