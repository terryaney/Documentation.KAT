Unified and Polished

KAT Command Center is now one unified app without the visual split between the container and its content. The entire application lives in the same window and follows your Dark, Light or System theme preference.

That brings a new Settings dialog, a themed loading screen, a new application bar, and keyboard and right-click behaviour that feels like an app rather than a web page. In addition to functional changes, both the light and dark theme were visually refined for a more polished experience and of course a batch of new features making KCC an even more powerful tool for managing your work than before.

Softer, yet clearer, appearance

The visual design of KAT Command Center has been refined to be softer and more modern, while maintaining clarity and readability across all themes. With KCC being the go to application of the KAT team, it was essential to ensure that the interface is both aesthetically pleasing and highly functional.

The application now features a theme picker to choose a theme that best suits your preference. Every aspect of the application was scrutinized and adjusted to ensure this vision was realized.

If you find any themes online that you believe would enhance the application, please share them with the development team for consideration.

  • Explore VS Code Themes - Sample themes. Each has variants discoverable by hovering over the different 'dots' under each preview.
  • Explore Coolors Palettes - Simply find a color palette that appeals to you that contains 5-8 different colors and lets turn it into a theme for KCC.

The new Settings dialog

The profile button  at the right of the app bar opens Settings. Hover it to see who you are signed in as for each account. It combines multiple setting management functions into a single, cohesive dialog.

Your passwords and token are never shown back to you. Their boxes stay empty, and an empty box means "keep what is saved".

Settings follows the app's theme and fits the window and shrinks from its full size in a smaller window when necessary.

  1. Profile holds your KAT DataStore, Conduent and TFS sign-ins.
  2. Display lets you choose separate palettes for Light and Dark modes, select Light, Dark or System color mode, and switch between Normal and Compact density.
  3. Work Items holds the settings that drive the functionality of viewing and managing work items. Queries are now added, edited and removed here rather than on the Work Items card: Add or Edit slides the query's settings over the page, a changed query shows a dot and an Undo, and nothing is saved until you press Save. See Creating Queries Views.
  4. Connections controls how the application connects to external services, including automatic updates, api polling, and online documentation.

Work Item Detail reads like a document and a conversation

Work Item Detail used to be two collapsible boxes you had to open before you could read anything. It is now the thing you actually came for: the description as prose at a comfortable measure, and the discussion underneath it as a single threaded conversation.

Comments carry the author's initials in a colored circle, and a person keeps the same color everywhere and between sessions, so you learn a thread's cast at a glance. A rail connects one comment to the next so a six-message back-and-forth reads as one exchange rather than six disconnected rows.

The summary line above the thread is also the controls. Click a person's initials to show only their comments and everyone else dims out; click again for everyone. Newest and Oldest flip the order, and the count re-reads itself for whatever is in view. A long description is trimmed to about four lines and fades out, with Show full description to open it - and the fade only appears once there is genuinely more to show, so a two-line description never looks truncated.

Comment bodies keep their formatting instead of flattening it. Code blocks, inline code, lists, bold and links all render, and a pasted screenshot is a real image you can click to enlarge rather than a broken box. Times read as 2 hours ago or Yesterday, with the exact timestamp on hover. See Work Item Detail.

  • A new Keyboard Shortcuts page in Help lists every shortcut in one place.
  • The application bar is part of the application. It stays in place as you scroll, follows the theme, and grows with everything else when you zoom with Ctrl+mouse wheel. In a narrow window the bar wraps onto two lines, Refresh shrinks to a ↻ icon and the filter button joins the icons on the right.
  • Errors and warnings now appear in a themed bar along the bottom of the window. A warning and an error can show at the same time, each with its own × to dismiss it, and a long message scrolls instead of taking over the window. The bar stays visible even while a dialog is open, without covering the dialog's buttons.
  • Each section's ↻ refresh button now shows its keyboard shortcut in its tooltip, for example "(Ctrl+Shift+R)" to refresh the Release Pipeline.
  • Unsaved edits in Add Comment, Triage, Return Task, Close Task and Create New are protected by Discard your changes?. In comment dialogs, Esc prompts only after a user edit; Cancel closes directly.
  • While the dashboard loads, the new loading screen shows what is happening to get KCC up and running.
  • Keys and right-click that behave like an app. 'Browser-like' behavior is minimized giving KCC a more native application feel. Hold Ctrl while you right-click to get the browser's menu anywhere (or F12), for troubleshooting.
  • The Work Items card is simpler: the add query button and each query's edit and delete buttons are gone, now that queries are managed in Settings. The bar reads Work Items, its ?, then Task ID Search, Search and Create New.
  • A query can now Hide chip when no work items present, so a query with nothing in it stops taking room on the bar. It is on for new queries; queries you already have keep their chips until you turn it on in Settings.
  • Ctrl+Shift+Q re-runs just the query whose results are open, the same as the ↻ at the end of its action bar.
  • A query's filter box names the query it filters, for example "Filter My To Do's items…".
  • Work Item Detail always shows Details and Links in a stable tab strip. A tab with no content is dimmed and unavailable; Links collects related work items, associated commits and builds.
  • The batch return flow is consistently named Return Triage Tasks in its action and dialog.
  • The Diagnostics trace now has a bounded scroll area, with jumps to the first entry, the first unseen entry and the newest entry.
  • Release Differences lets you collapse commits by repository or hide a whole release group while keeping its headers fixed during scrolling.
  • CalcEngine Pipeline's download action now uses a download arrow instead of a save icon.
  • Copying a work-item ID includes its # prefix, and Task ID Search accepts that prefix when pasted.
  • Conduent links show an orange border on hover.
  • The footer's product and generated text is gone; zoom guidance now sits in the header before Last Refresh.
  • The production-release check for the site-picker dot is configurable in Settings, with a 20-minute default.
  • When the Microsoft Edge WebView2 Runtime is missing, the app now says so in plain words, with a link to download it, instead of crashing with a technical error box.
  • Pressing Alt on its own no longer leaves the keyboard unresponsive on every second press.
  • Scrollbars are the same thin style everywhere, including the site picker, the message bar and Settings.
  • CalcEngine Pipeline rows now keep controls beside the CalcEngine name on wide cards and move them below on narrower cards. Long checkout labels shorten with an ellipsis instead of crossing the row border; hover still shows the full details.
  • Complete editorial review of the help documentation.
  • Task ID Search now matches the height of a query's filter field.
  • Icon-only buttons are square, with standard controls at 28px and compact controls matching neighboring text buttons; Task Detail also loses its divider bars.
